FUNDAMENTALS

Core Queueing Concepts

  • Arrival Rate (λ): λ = 1 / Mean Inter-Arrival Time
  • Service Rate (μ): μ = 1 / Mean Service Time
  • Utilization (ρ): ρ = λ / μ (Must be < 1.0 for steady-state stability)
  • Little's Law: L = λ × W | Lq = λ × Wq
  • System Relationship: W = Wq + (1 / μ) | L = Lq + ρ
SINGLE PUMP (c = 1)

M/M/1, M/G/1 & G/G/1 Formulas

  • M/M/1 (Poisson Arrivals, Exponential Service): Lq = ρ² / (1 - ρ) Wq = Lq / λ = ρ / [μ(1 - ρ)] Probability system is idle: P₀ = 1 - ρ
  • M/G/1 (Pollaczek–Khinchine Formula): Lq = (λ²σ² + ρ²) / [2(1 - ρ)] Wq = Lq / λ Proves service variance (σ²) directly lengthens queue size and wait time.
  • G/G/1 (Sakasegawa Single-Server Approx): Wq ≈ [ρ / (1 - ρ)] × [(Ca² + Cs²) / 2] × (1/μ) Lq = λ × Wq Variation coefficients: Ca² = (σa / Mean_a)², Cs² = (σs / Mean_s)²
OPERATING RULES

Stability & Capacity Insights

  • Kendall's Notation: A / B / 1 (Arrival / Service / Single Pump)
  • Stable State: ρ = λ / μ < 1.0 (Queue reaches steady-state equilibrium)
  • Bottleneck / Saturation: If λ ≥ μ (ρ ≥ 1.0), cars arrive faster than service, queue grows infinitely
  • Variance Penalty: Higher standard deviation (σ) increases line delay even if average speed is constant
  • Discipline: First-In, First-Out (FIFO) queue with infinite buffer capacity
